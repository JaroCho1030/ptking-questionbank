## 怎麼歸類（通則）

- 每題 1 個**主要主題**，另可掛 0～2 個**次要主題**。次要主題只用在題目真的同時考兩個主題時（全題庫約 1%），不拿來表示「不確定」。
- **看考的是什麼，不看情境**：題幹用某疾病當情境，但實際考的是量表、手法或解剖，就歸量表、手法或解剖那個主題。
- **主要主題先看本科**（題目所在試卷的科目）：本科有**專門**涵蓋這個考點的主題就留本科，例如神經科試卷考神經解剖 → NEURO-FOUND、心肺試卷考冠狀動脈分支 → CARDPED-CV-FOUND。
- **本科只有籠統或勉強相關的主題、而別科有專門的主題時，選別科**，不另掛本科次要主題（例：概論試卷考良性陣發性姿勢性眩暈 → NEURO-VESTIB、骨科試卷考 Kaltenborn 肩關節鬆動 → TECH-JOINTMOB、技術學試卷考 Wernicke 失語症是哪一區受損 → BASIC-ANA-NEU）。
- **本科試卷單純問解剖構造或神經支配範圍**（例：食指掌側感覺由哪條神經支配）：主要主題選本科最接近的主題，次要主題加基礎學的解剖主題（BASIC-ANA-*）；若問的是損傷後的表現或處置，就只標本科主題。
- 「不含」列的是容易混淆、但要歸到別處的內容；箭頭後面是該歸的主題。
- App 裡的篩選與統計：選了某個主題，主要或次要主題符合的題目都會出現；各主題正確率主要、次要各算 1 題，所以各主題題數加總會大於總題數。

## 物理治療基礎學（BASIC，16 個主題）

### 解剖學

<a id="basic-ana-msk"></a>

#### BASIC-ANA-MSK　肌肉骨骼系統解剖學（構造、位置、起止點、神經支配）

- **包含**：骨骼、肌肉、韌帶、關節的構造與位置：起止點、神經支配、血液供應、關節組成與軟骨分類。
- **不含**：肌肉在動作中的功能、關節穩定與力學（足弓基石、單腳站立誰在固定）→ 該部位的 KIN 主題
- **關鍵字**：骨骼、肌肉起止點、韌帶、關節構造、關節組成、軟骨分類、神經支配、血液供應

<a id="basic-ana-neu"></a>

#### BASIC-ANA-NEU　神經系統解剖學

- **包含**：腦、脊髓、腦神經與周邊神經的構造、傳導路徑、皮節與肌節。
- **不含**：神經訊號的產生與傳遞（動作電位、突觸）→ [BASIC-PHY-NEU](#basic-phy-neu)
- **關鍵字**：腦、脊髓、腦神經、周邊神經、傳導路徑、皮節、肌節

<a id="basic-ana-cp"></a>

#### BASIC-ANA-CP　呼吸循環系統解剖學

- **包含**：心臟、血管、肺、氣道、縱膈與冠狀動脈的構造與位置。
- **不含**：心輸出量、血壓調控、氣體交換等功能 → [BASIC-PHY-CP](#basic-phy-cp)
- **關鍵字**：心臟、血管、肺、氣道、縱膈、冠狀動脈

<a id="basic-ana-oth"></a>

#### BASIC-ANA-OTH　其他系統解剖學

- **包含**：消化、泌尿、生殖、內分泌、皮膚系統的構造，以及胚胎發育。
- **關鍵字**：消化、泌尿、生殖、內分泌、皮膚、胚胎

### 生理學

<a id="basic-phy-msk"></a>

#### BASIC-PHY-MSK　肌肉骨骼系統生理學（含肌肉收縮機制、骨骼肌與運動時的能量代謝）

- **包含**：肌肉收縮機制（橫橋、離心收縮的機制、長度－張力關係）、肌纖維型態、骨骼肌與運動時的能量系統（ATP、乳酸、脂肪氧化）、骨代謝。
- **不含**：
  - 某個動作由哪條肌肉、哪種收縮型態完成 → [BASIC-KIN-ANALYSIS](#basic-kin-analysis) 或該部位的 KIN 主題
  - 心肌的能量代謝 → [BASIC-PHY-CP](#basic-phy-cp)
  - 蛋白質、維生素等一般營養代謝 → [BASIC-PHY-OTH](#basic-phy-oth)
- **關鍵字**：肌肉收縮、橫橋、離心收縮機制、長度張力關係、肌纖維型態、能量系統、ATP、乳酸、脂肪氧化、骨代謝

<a id="basic-phy-neu"></a>

#### BASIC-PHY-NEU　神經內分泌系統生理學

- **包含**：動作電位、突觸、反射、感覺受器、自主神經與荷爾蒙的作用。
- **關鍵字**：動作電位、突觸、反射、感覺受器、荷爾蒙、自主神經

<a id="basic-phy-cp"></a>

#### BASIC-PHY-CP　呼吸循環系統生理學（含心肌能量代謝）

- **包含**：心輸出量、血壓調控、氣體交換、肺容積、血液，以及心肌的能量代謝。
- **關鍵字**：心輸出量、血壓調控、氣體交換、肺容積、血液、心肌代謝

<a id="basic-phy-oth"></a>

#### BASIC-PHY-OTH　其他系統生理學（含一般營養代謝）

- **包含**：消化、腎臟、酸鹼平衡、體溫、免疫、皮膚生理，以及蛋白質、維生素等一般營養代謝。
- **不含**：骨骼肌與運動時的能量來源 → [BASIC-PHY-MSK](#basic-phy-msk)
- **關鍵字**：消化、腎臟、酸鹼平衡、體溫、免疫、皮膚、蛋白質代謝、維生素、營養代謝

<a id="basic-phy-ex"></a>

#### BASIC-PHY-EX　運動生理學、發展與老化

- **包含**：最大攝氧量、訓練適應、疲勞、臥床去適能，以及生長發育與老化的生理變化。
- **關鍵字**：最大攝氧量、訓練適應、疲勞、發展、老化生理

### 肌動學與生物力學

<a id="basic-kin-theory"></a>

#### BASIC-KIN-THEORY　肌動學與生物力學理論

- **包含**：力矩、槓桿、牛頓定律、骨運動學與關節運動學（凹凸法則）等不限部位的力學原理，以及肌肉型態與力量的關係（羽狀肌、生理截面積）。
- **不含**：特定部位的肌動學 → [BASIC-KIN-UE](#basic-kin-ue)／LE／SPINE
- **關鍵字**：力矩、槓桿、牛頓定律、關節運動學、骨運動學、凹凸法則

<a id="basic-kin-ue"></a>

#### BASIC-KIN-UE　上肢肌動學

- **包含**：肩胛肱骨節律、肘、前臂、腕、手與抓握的運動與上肢肌肉功能。
- **不含**：只問構造、起止點、神經支配 → [BASIC-ANA-MSK](#basic-ana-msk)
- **關鍵字**：肩胛肱骨節律、肘、前臂、腕、手、抓握、上肢肌肉功能

<a id="basic-kin-le"></a>

#### BASIC-KIN-LE　下肢肌動學

- **包含**：髖、膝、踝、足的運動與穩定：足弓與足弓基石、單腳站立、螺旋回返、Q 角與下肢肌肉功能。
- **不含**：
  - 只問構造、起止點、神經支配 → [BASIC-ANA-MSK](#basic-ana-msk)
  - 步態週期 → [BASIC-KIN-GAIT](#basic-kin-gait)
- **關鍵字**：髖、膝、踝、足弓、足弓基石、單腳站立、螺旋回返、Q角、下肢肌肉功能

<a id="basic-kin-spine"></a>

#### BASIC-KIN-SPINE　頭頸軀幹肌動學

- **包含**：脊椎、椎間盤、顳頷關節、骨盆與呼吸肌的運動，包括耦合動作與小面關節的滑動方向。
- **關鍵字**：脊椎、椎間盤、顳頷關節、骨盆、呼吸肌、耦合動作

<a id="basic-kin-gait"></a>

#### BASIC-KIN-GAIT　步態與姿態

- **包含**：步態週期與各期肌肉活動、步態決定因子、跑步分期、站姿與姿勢、重心與壓力中心。
- **關鍵字**：步態週期、步態決定因子、姿勢、重心、壓力中心

<a id="basic-kin-analysis"></a>

#### BASIC-KIN-ANALYSIS　人體動作技巧與分析（某個動作由哪條肌肉、哪種收縮型態完成）

- **包含**：具體動作（伏地挺身、投擲、跳、游泳、懸吊訓練）由哪些肌肉、哪種收縮型態完成；肌電圖與動作捕捉分析。
- **不含**：收縮本身的機制 → [BASIC-PHY-MSK](#basic-phy-msk)
- **關鍵字**：動作分析、收縮型態、肌電圖、動作捕捉、跑、跳、投擲、伏地挺身

<a id="basic-kin-tissue"></a>

#### BASIC-KIN-TISSUE　組織生物力學

- **包含**：骨、肌腱、韌帶、軟骨的力學特性：應力應變、黏彈性、潛變、鬆弛。
- **關鍵字**：應力應變、黏彈性、潛變、骨、肌腱、韌帶、軟骨

#### CARDPED-RESP-TX　肺部疾病物理治療與肺部復健

- **關鍵字**：COPD、氣喘、肺炎、氣胸、限制型肺疾、胸腔手術、姿位引流、呼吸訓練、機械通氣輔助、IPPB、肺部復健

<a id="cardped-cv-found"></a>

#### CARDPED-CV-FOUND　循環系統物理治療原理與機轉

- **包含**：心臟生理、血流動力學、心肌氧耗、自主神經對循環的調控、姿勢改變的循環反應。
- **不含**：訓練後的適應、臥床去適能 → [CARDPED-EXPHYS](#cardped-exphys)
- **關鍵字**：心臟生理、血流動力學、心肌氧耗、自主神經

#### CARDPED-CV-ASSESS　循環系統評估（心電圖、運動測試）

- **不含**：無氧閾值等運動生理概念 → [CARDPED-EXPHYS](#cardped-exphys)
- **關鍵字**：心電圖、心律不整、運動測試、MET、RPE、血壓反應

- **關鍵字**：心肌梗塞、心衰竭、心臟手術、心臟復健分期、周邊血管疾病

- **關鍵字**：運動生理、訓練適應、耐力訓練、臥床、去適能、無氧閾值、乳酸閾、換氣閾、最大攝氧量、動靜脈氧差、兒童運動反應

#### CARDPED-HP　健康促進與運動處方

- **關鍵字**：ACSM、FITT、運動處方、代謝症候群、糖尿病、肥胖、體適能
